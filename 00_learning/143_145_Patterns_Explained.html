JavaScript patterns, made simple

How do these star patterns work?

Imagine building a picture one line at a time. The outside loop chooses the line, and the inside loop decides how many stars or spaces go on it.

These examples explain 143_Right_Hand_Pattern.js, 144_Left_Hand_Pattern.js, and 145_Pyramid_Pattern.js.

First: what do the two loops do?

Think of a printer making a picture row by row. The outside loop says, “Start the next row.” The inside loop says, “Print this row's characters.” 

outside loop: choose a row
  inside loop: print the row's characters
outside loop: choose the next row
  inside loop: print that row's characters

When the inside loop finishes, the program moves to a new line. Then the outside loop starts the next row.

143: the triangle that grows

This program uses n = 8, so it prints eight rows. The outside counter i starts at zero. The inside loop prints one more star each time. 

let n = 8;

for (i = 0; i < n; i++) {
    for (j = 0; j <= i; j++) {
        process.stdout.write("*");
    }
    console.log("");
}

Read the code one step at a time

  1. let n = 8; sets the pattern size. This program will print 8 rows.
  2. for (i = 0; i < n; i++) is the outside loop. It begins with i = 0, keeps going while i is less than 8, and adds 1 to i after each row. So i takes the values 0 through 7.
  3. for (j = 0; j <= i; j++) is the inside loop. It starts j at 0 and repeats until j is greater than i. Because both 0 and i are included, it prints i + 1 stars.
  4. process.stdout.write("*"); prints one star without starting a new line. The inside loop runs this line over and over for the current row.
  5. The first closing brace ends the inside loop. Then console.log(""); moves to a new line, ready for the next row.
  6. The last closing brace ends the outside loop. The program stops after it has printed all 8 rows.
Watch the first rows:
  • i = 0: j is 0 once, so print *.
  • i = 1: j is 0, then 1, so print **.
  • i = 2: j is 0, 1, then 2, so print ***.

Each time the outside loop picks a new row, j starts over at 0.

Small code note: this file uses i and j without declaring them. Use let in each loop to avoid creating global variables or getting an error in strict mode.

144: the triangle that shrinks

This one starts with five stars. The outside counter i counts down from 5 to 1, so every new row gets one fewer star. 

let n = 5;

for (let i = n; i >= 1; i--) {
    for (let j = 1; j <= i; j++) {
        process.stdout.write("*");
    }
    console.log("");
}

Read the code one step at a time

  1. let n = 5; sets the size to 5, so the first row will have 5 stars.
  2. for (let i = n; i >= 1; i--) is the outside loop. It starts i at 5, keeps going while i is at least 1, and subtracts 1 after each row.
  3. for (let j = 1; j <= i; j++) is the inside loop. It repeats i times, because j counts from 1 through i.
  4. process.stdout.write("*"); prints one star each time the inside loop repeats, without moving to a new line.
  5. When the inside loop is finished, console.log(""); ends that row. The outside loop then subtracts 1 from i and starts the next row.
  6. The outside loop stops after the row where i is 1.
Watch the countdown:
  • i = 5: print 5 stars.
  • i = 4: print 4 stars.
  • i = 3: print 3 stars.
  • Then 2 stars, then 1 star. After that, i becomes 0, so i >= 1 is false and the loop ends.

The filename calls this the “left hand” pattern. The code is what tells us exactly what it looks like: these rows are all left-aligned and get shorter.

145: the pyramid

The pyramid needs stars and spaces. Each row is first built in a string called row, then printed all at once. 

let n = 3;

for (let i = 1; i <= n; i++) {
    let row = "";
    for (let j = 1; j <= n - i; j++) {
        row += " ";
    }
    for (let j = 1; j <= 2 * i - 1; j++) {
        row = row + "*";
    }
    console.log(row);
}

Read the code one step at a time

  1. let n = 3; sets the height of the pyramid to 3 rows.
  2. for (let i = 1; i <= n; i++) is the outside loop. It chooses rows 1, 2, and 3.
  3. let row = ""; starts a fresh, empty string for this row. Starting fresh means the new row does not contain characters from the previous row.
  4. for (let j = 1; j <= n - i; j++) counts how many leading spaces to add. The first row gets 3 - 1 = 2 spaces; the second gets 1; the third gets 0.
  5. row += " "; adds one space to the end of row each time that first inside loop repeats.
  6. for (let j = 1; j <= 2 * i - 1; j++) counts how many stars to add. The row gets 1, 3, then 5 stars.
  7. row = row + "*"; adds one star to the end of the row each time that second inside loop repeats.
  8. console.log(row); prints the completed row and starts a new line.
  9. After printing, the outside loop increases i. The program starts an empty string and builds the next row.
Build each row:
  • i = 1: add 2 spaces, then 1 star: *.
  • i = 2: add 1 space, then 3 stars: ***.
  • i = 3: add 0 spaces, then 5 stars: *****.

For each row, the program does two small jobs:

  1. Add spaces at the beginning: n - i spaces.
  2. Add stars after the spaces: 2 * i - 1 stars.

The stars go 1, 3, 5: two more each time. The spaces go 2, 1, 0: one fewer each time. That is how the pyramid grows in the middle.

Quick recap

  • The outside loop makes the rows.
  • The inside loop decides what goes in each row.
  • The first pattern adds one star on every row.
  • The second pattern removes one star on every row.
  • The pyramid adds spaces first so its stars look centered.
  • process.stdout.write() stays on the same line; console.log() starts a new one.
