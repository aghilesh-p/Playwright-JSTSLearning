Why does changing b also change a?

The key idea: assigning an object to another variable copies its reference, not the object itself. Both variables lead to the same object. 

let a = {
  status: "Pass"
};
let b = a;
b.status = "Fail";
console.log(a.status);

Step by step

  1. a refers to an object whose status is "Pass".
  2. b = a copies the reference, so a and b refer to that same object.
  3. b.status = "Fail" changes the shared object's property.
  4. a.status reads that changed property, so the output is "Fail".

Console output: Fail

To keep the objects independent, create a copy, for example let b = { ...a };. This makes a shallow copy, so nested objects are still shared.
