# Playwright-JSTSLearning

Learning JavaScript and TypeScript fundamentals as a foundation for working with Playwright and AI.

## Chapters

### 1. JavaScript Basics

- `01_Chapter_JS_Basics/01_HelloWorld.js` - print a Hello World message.
- `01_Chapter_JS_Basics/02_math.js` - try basic arithmetic operators.

### 2. Keywords and Identifiers

- `02_Chapter_Keywords_and_Identifiers/03_js_engine.js` - explore cold code and repeatedly executed hot code.
- `02_Chapter_Keywords_and_Identifiers/04_litengine.js` - identify a keyword, identifier, operator, and literal in a statement.
- `02_Chapter_Keywords_and_Identifiers/05_KW_IDE.js` - compare `var`, `let`, and `const`.
- `02_Chapter_Keywords_and_Identifiers/06_KW_IDE_rules.js` - review valid and invalid identifier examples.
- `02_Chapter_Keywords_and_Identifiers/07_KW_IDE_rules2.js` - explore common JavaScript naming conventions.
- `02_Chapter_Keywords_and_Identifiers/08_Comments.js` - see single-line, multi-line, and JSDoc comments.
- `02_Chapter_Keywords_and_Identifiers/09_IQ.js` - explore identifier rules, case sensitivity, naming styles, and Unicode identifiers.

### 3. JavaScript Literals

- `03_Chapter_JS_Literals/10_Literals.js` - review common literal values and their types.
- `03_Chapter_JS_Literals/11_literal_types.js` - assign a literal value to a variable.
- `03_Chapter_JS_Literals/12_Null_Undefined.js` - compare `null` and `undefined` values and their types.
- `03_Chapter_JS_Literals/13_Null_Undefined2.js` - see examples of `null` and `undefined`.
- `03_Chapter_JS_Literals/14_Literals_IQ.js` - explore `null` and `undefined` with comparison examples.
- `03_Chapter_JS_Literals/15_Numbers.js` - explore integer, floating-point, and exponential number literals.
- `03_Chapter_JS_Literals/16_Numbers_part2.js` - use numeric separators and BigInt values.
- `03_Chapter_JS_Literals/17_Special.js` - explore `Infinity`, `-Infinity`, and `NaN`.
- `03_Chapter_JS_Literals/18_IQ.js` - examine `undefined`, `null`, number bases, and array length.

### 4. JavaScript Operators

- `04_Chapter_JS_Operators/19_Arch.js` - identify operators in an expression.
- `04_Chapter_JS_Operators/20_Assignment_OP.js` - assign and update variable values.
- `04_Chapter_JS_Operators/21_Arithmetic_OP.js` - use arithmetic, remainder, and exponentiation operators.

- `04_Chapter_JS_Operators/28_Ternary_OP_Eg.js` - compare actual and expected status codes with a ternary expression.
- `04_Chapter_JS_Operators/29_Int_Q.js` - select an API URL based on the environment.
- `04_Chapter_JS_Operators/30_Int_Q.js` - select headed or headless browser mode based on CI.
- `04_Chapter_JS_Operators/31_Int_Q.js` - evaluate an SLA and interpolate values in a template literal.
- `04_Chapter_JS_Operators/32_Int_Q.js` - evaluate a Boolean condition with the ternary operator.
- `04_Chapter_JS_Operators/33_Nested_Ternary_OP.js` - evaluate nested ternary conditions.
- `04_Chapter_JS_Operators/34_Int_Q.js` - categorize an HTTP status code with nested conditions.
- `04_Chapter_JS_Operators/35_Int_Q.js` - categorize a temperature with nested conditions.
- `04_Chapter_JS_Operators/36_TypeOf_OP.js` - inspect the types of strings, numbers, Booleans, `undefined`, and `null`.

- `05_Chapter_JS_Incr_Decr_OP/42_Pre_Dec_OP.js` - observe the value returned by prefix decrement.

### 6. JavaScript If/Else Statements and Conditions

- `06_Chapter_JS_IF_ELSE_Statement_Condition/45_If_Else.js` - choose an outcome with a basic `if`/`else` condition.
- `06_Chapter_JS_IF_ELSE_Statement_Condition/46_If_Else_Nested.js` - evaluate nested conditions for driving eligibility.

- `08_Chapter_JS_UserInputs/58_UserInput.js` - read a browser prompt and check whether a number is even or odd.

## Running an example

Install [Node.js](https://nodejs.org/), install the project dependencies, and run a script from the repository root:

```sh
npm install
node 01_Chapter_JS_Basics/01_HelloWorld.js
```

Replace the script path with any other `.js` file in the chapters to run a different example.
The `prompt-sync` dependency is used by the synchronous terminal input example.
