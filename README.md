# Playwright-JSTSLearning

Learning JavaScript and TypeScript fundamentals as a foundation for working with Playwright and AI.

## Chapters

- `01_Chapter_JS_Basics/01_HelloWorld.js` - print a Hello World message.
- `01_Chapter_JS_Basics/02_math.js` - try basic arithmetic operators.

- `02_Chapter_Keywords_and_Identifiers/09_IQ.js` - explore identifier rules, case sensitivity, naming styles, and Unicode identifiers.

## Running an example

Install [Node.js](https://nodejs.org/), install the project dependencies, and run a script from the repository root:

```sh
npm install
node 01_Chapter_JS_Basics/01_HelloWorld.js
```

Replace the script path with any other `.js` file in the chapters to run a different example.
The `prompt-sync` dependency is used by the synchronous terminal input example.
